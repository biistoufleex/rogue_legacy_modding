## Résumé court (350 caractères max)

> Unofficial mod: drop-in local 2-player co-op for Rogue Legacy. Plug a second gamepad, press START and Player 2
> joins next to you — shared arcade-style camera, class powers, revives. Play online with Parsec. Built from Cellar
> Door Games' official source code. No game files included: you need to own Rogue Legacy.

[size=4][b]Rogue Legacy — CO-OP (UNOFFICIAL MOD)[/b][/size]

[b][color=#ff6666]This is an unofficial, modified version of Rogue Legacy 1. It is not made, endorsed or supported by Cellar Door Games.[/color][/b]
Rogue Legacy is © Cellar Door Games 2013-2024. This mod is based on the Rogue Legacy 1 source code released by Cellar Door Games ([url=https://github.com/flibitijibibo/RogueLegacy1]github.com/flibitijibibo/RogueLegacy1[/url]) under the Rogue Legacy Source Code License (non-commercial). It is free, contains [b]no game files[/b] and you must [b]own Rogue Legacy[/b] to play it.

[size=3][b]Drop-in local co-op, arcade style[/b][/size]
[list]
[*][b]Join[/b]: plug a 2nd gamepad and press [b]START[/b] — Player 2 appears next to Player 1, anywhere. One gamepad only? Player 1 on keyboard, [b]SELECT + START[/b] on the pad.
[*][b]Class[/b]: in the starting camp, short press on [b]SELECT[/b] cycles Knight / Mage / Barbarian. Upgraded class powers (Paladin statue, Archmage spell swap, Barbarian King shout) if unlocked in your manor.
[*][b]Leave[/b]: hold [b]SELECT[/b] for 3 seconds.
[*]Same controls as Player 1 (A jump, X attack, Y class power, B spell, triggers dash).
[*]Shared [b]Metal Slug-style camera[/b]: the screen edges are invisible walls for both players.
[*]Enemies target the [b]nearest player[/b]; kill rewards (mana, vampirism…) go to whoever landed the hit.
[*]Player 2 is knocked out for 8 s, then comes back. If Player 1 dies, the lineage goes on and Player 2 comes back next life.
[*]Player 1 handles chests, teleporters, boss doors, the map and the gold. Player 2 is not saved.
[*][b]Online[/b]: use [url=https://parsec.app/]Parsec[/url] — the remote player's gamepad becomes gamepad 2.
[*]Own save slot: your Steam saves (and Steam Cloud) are never modified.
[/list]
Want guns? See the companion mod [b]Rogue Legacy - Weapons[/b].

[size=3][b]Installation[/b][/size]
[list=1]
[*]Extract the archive anywhere ([b]not[/b] inside your Steam game folder).
[*]Double-click [b]install.bat[/b] (copies the game's Content folder from your Steam copy, creates the mod's save slot).
[*]Launch [b]RogueLegacy.exe[/b]. Optional: Steam > [i]Add a Non-Steam Game[/i].
[/list]
Windows 64-bit only. Steam achievements are disabled in the mod.
If Windows shows [i]"Windows protected your PC"[/i] (the exe is not signed): [b]More info > Run anyway[/b].

[size=3][b]Known issues[/b][/size]
[list]
[*]Windows only (no Linux / Steam Deck build yet).
[*]Added to Steam as a non-Steam game and a gamepad is not detected? Disable [b]Steam Input[/b] for that shortcut (Properties > Controller).
[*]Only Player 1 navigates the pause menu and the other menus.
[*]Chests, teleporters, boss doors, map, NPCs and gold are handled by Player 1; Player 2 changes class only in the starting camp.
[*]An idle Player 2 on a screen edge blocks Player 1 (arcade rule): Player 2 can leave with SELECT (3 s).
[/list]
