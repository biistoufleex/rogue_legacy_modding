ENGLISH
-------
Requirements: Windows 64-bit, Rogue Legacy installed (Steam), .NET Framework 4.x
(already included in Windows 10/11), 1 or 2 gamepads.

Install:
 1. Extract this archive anywhere (NOT inside your Steam game folder).
 2. Right-click install.ps1 > "Run with PowerShell".
    It copies the game's "Content" folder from your Steam copy and gives the mod its own
    save slot (a copy of your saves). Your Steam game and saves are never modified.
 3. Launch RogueLegacy.exe. Optional: Steam > "Add a Non-Steam Game" > RogueLegacy.exe.

Drop-in local co-op (arcade style):
 - JOIN   : plug a 2nd gamepad and press START. Player 2 appears next to Player 1, anywhere.
            One gamepad only? Player 1 plays on keyboard, press SELECT + START on the pad.
 - CLASS  : in the starting camp, short press on SELECT cycles Knight / Mage / Barbarian.
            Upgraded class powers (Paladin, Archmage, Barbarian King) if unlocked in your manor.
 - LEAVE  : hold SELECT for 3 seconds (or unplug the gamepad).
 - Player 2 uses the same layout as Player 1: A jump, X attack, Y class power, B spell,
   triggers dash, START pause.
 - Shared Metal Slug-style camera: the screen edges are invisible walls for both players.
 - Enemies target the nearest player. Player 2 is knocked out for 8 s, then comes back.
   If Player 1 dies, the normal lineage screen follows and Player 2 comes back next life.
 - Player 1 handles chests, teleporters, boss doors, the map and the gold. Player 2 is not saved.
 - Online: use Parsec - the remote player's gamepad becomes gamepad 2.
 - Steam achievements are disabled in the mod.


FRANCAIS
--------
Prerequis : Windows 64 bits, Rogue Legacy installe (Steam), .NET Framework 4.x
(deja present dans Windows 10/11), 1 ou 2 manettes.

Installation :
 1. Extraire l'archive n'importe ou (PAS dans le dossier du jeu Steam).
 2. Clic droit sur install.ps1 > "Executer avec PowerShell".
    Le script copie le dossier "Content" depuis votre jeu Steam et cree un emplacement de
    sauvegarde propre au mod (copie de vos saves). Le jeu Steam et vos saves ne sont jamais modifies.
 3. Lancer RogueLegacy.exe. Optionnel : Steam > "Ajouter un jeu non-Steam" > RogueLegacy.exe.

Coop local "drop-in" (facon arcade) :
 - REJOINDRE : branchez une 2e manette et appuyez sur START. Le joueur 2 apparait sur le joueur 1.
               Une seule manette ? Joueur 1 au clavier, SELECT + START sur la manette.
 - CLASSE    : au camp de depart, appui court sur SELECT : Chevalier / Mage / Barbare.
               Pouvoirs des classes ameliorees (Paladin, Archimage, Roi barbare) si debloques au manoir.
 - QUITTER   : maintenir SELECT 3 secondes (ou debrancher la manette).
 - Meme disposition que le joueur 1 : A saut, X attaque, Y pouvoir de classe, B sort,
   gachettes dash, START pause.
 - Camera partagee facon Metal Slug : les bords de l'ecran sont des murs invisibles.
 - Les ennemis visent le joueur le plus proche. Le joueur 2 est K.O. 8 s puis revient.
   Si le joueur 1 meurt : ecran de lignee normal, le joueur 2 revient a la vie suivante.
 - Le joueur 1 gere coffres, teleporteurs, portes de boss, carte et or. Le joueur 2 n'est pas sauvegarde.
 - En ligne : utilisez Parsec (la manette du joueur distant devient la manette 2).
 - Les succes Steam sont desactives dans le mod.
